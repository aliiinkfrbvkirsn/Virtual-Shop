# Virtual Shop

Мобильный демонстрационный интернет-магазин на HTML, CSS и JavaScript без сборщика.

## Структура

- `index.html` — семантическая разметка и подключение ресурсов.
- `styles.css` — все стили и адаптивная вёрстка.
- `js/data.js` — демо-каталог и переводы RU/KG.
- `js/storage.js` — единый слой чтения и записи локальных данных с защитой от повреждённого JSON и ошибок хранилища.
- `js/app.js` — состояние интерфейса, события и рендеринг.
- `js/auth.js` — регистрация, подтверждение почты, вход/выход и профиль через Supabase Auth.
- `sw.js` — service worker и кеширование оболочки приложения.

## Поток данных

`index.html → js/app.js → (js/data.js, js/storage.js, js/auth.js) → localStorage + Supabase Auth`

## Ограничения текущего этапа

Регистрация и вход выполняются через Supabase Auth. Подтверждение email отправляется на адрес пользователя; URL возврата должен быть добавлен в Supabase Auth → URL Configuration. Каталог, корзина и демо-заказы пока используют локальное хранилище браузера; общая синхронизация с таблицами Supabase и реальные платежи требуют отдельного этапа.

## Запуск

Откройте опубликованную GitHub Pages-версию. Для локального тестирования используйте любой статический HTTP-сервер; ES-модули не запускаются надёжно через адрес `file://`. Клиент Supabase загружается как ES-модуль с CDN и требует интернет-соединения.
